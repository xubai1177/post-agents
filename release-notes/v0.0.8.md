## 更新

- 新增工作区切换入口，支持打开最近使用的工作区和创建新工作区。
- 优化选题工作台和任务面板，集中查看选题及文章生成任务的状态和结果。
- 平台设置支持测试正文和标题生成规则，方便在应用前查看生成效果。
- 改进工作区备份与恢复，支持导出进度、无密码备份和密码加密备份。无密码备份不包含 API 密钥；加密备份包含密钥，请妥善保管密码。
- 优化内容目录、文章操作和设置界面的布局与交互。

## 安装说明

- Windows 用户可通过应用内更新，或下载安装包；Mac 用户请选择对应芯片架构的安装包。
- 更新前请完成正在进行的任务并保存内容。
- Windows 与 Mac 安装包尚未配置正式代码签名，系统可能显示安全提示。
